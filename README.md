# MATH-ENGINE

**Математика, которую можно потрогать.**

Тригонометрия в школе выглядит как набор формул, которые надо зазубрить. А на самом деле это просто точка, которая бегает по кругу. MATH-ENGINE даёт тебе эту точку в руки: хватай, тяни и смотри, что происходит с синусом, косинусом и тангенсом.

Без установки, без сборки, без сервера. Открыл файл, и всё работает.

---

## Что внутри

### 🎯 Тригонометрический круг
Тащи точку по окружности. Синус, косинус и тангенс рисуются отрезками прямо на круге, а значения обновляются вживую. Хочешь точности: включи шаг 15° и прыгай по «красивым» углам.

### 📈 Графики sin, cos, tg, ctg
Круг «разворачивается» в волну. Двигай угол и смотри, как точка на круге и точка на графике ходят в паре. Можно включать и выключать функции, сдвигать график по горизонтали (φ) и по вертикали (d), а у тангенса и котангенса видны пунктирные асимптоты.

### 🌐 Единичная сфера (3D)
Круг получил третье измерение. Два угла, θ и ψ, задают точку на сфере. Крути сферу мышкой или пальцем и смотри на проекции на оси. Координаты `x = cos ψ cos θ`, `y = cos ψ sin θ`, `z = sin ψ` считаются на лету.

## Запуск

1. Положи `index.html` и `style.css` в одну папку.
2. Открой `index.html` в браузере.

Всё. React и шрифт подтягиваются с CDN, поэтому нужен интернет. Работает на телефоне, есть светлая и тёмная тема.

## Управление

| Что сделать | Как |
|---|---|
| Задать угол | Тащить точку, ввести число или нажать на быстрый выбор (0°, 30°, 45°…) |
| Тонкая подстройка | Стрелки ← → на точке круга |
| Градусы или радианы | Переключатель рядом с полем угла |
| Крутить сферу | Тащить по полю |
| Скрыть функцию на графике | Клик по её имени в легенде |
| Сменить тему | Кнопка «Тема» |

## Как это устроено

Это один HTML-файл на React 18 (через CDN, без сборки), вся графика нарисована на чистом SVG. Никаких тяжёлых библиотек: 3D-сфера считается обычной ортографической проекцией, а перетаскивание сделано через pointer events.

Весь движок устроен вокруг реестра инструментов:

```jsx
const TOOLS = [
  { id: 'circle', name: 'Тригонометрический круг', hint: 'sin, cos, tg', Comp: UnitCircle },
  { id: 'graph',  name: 'Графики sin, cos, tg, ctg', hint: 'связаны с кругом', Comp: Graph },
  { id: 'sphere', name: 'Единичная сфера (3D)', hint: 'углы θ и ψ', Comp: Sphere },
];
```

Угол θ общий для всех инструментов: передвинул точку на круге, и она сдвинулась на графике и на сфере.

## Добавить свой инструмент

1. Напиши компонент, который принимает `st` (общее состояние: `theta`, `psi`, `snap`, сдвиги…) и рисует `<svg>`.
2. Добавь одну строку в `TOOLS`.
3. Если нужны свои ползунки, допиши блок в `Props`: `{tool.id === 'твой-id' && …}`.

Идеи для следующих инструментов: векторы и скалярное произведение, поверхность `z = f(x, y)`, комплексная плоскость, фигуры Лиссажу.
